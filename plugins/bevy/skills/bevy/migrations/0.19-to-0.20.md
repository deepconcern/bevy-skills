# Migrating a game from Bevy 0.19 to 0.20

Distilled from the official guide (https://bevy.org/learn/migration-guides/0-19-to-0-20/, source
`content/learn/migration-guides/0.19-to-0.20.md` in bevyengine/bevy-website, MIT). The full guide
also ships in the crate as `bevy-0.20.1/_release-content/migration-guides/`. This file covers the
changes that typical game code hits. Engine internals, render-world and reflection details are left
to the official guide.

When 0.21 ships, the still-relevant rows here move into `references/0.21/stale-apis.md`, and this
file is replaced by `0.20-to-0.21.md`.

## Upgrade steps

1. Toolchain: Bevy 0.20.1 needs **rustc 1.97.1+**. Run `rustup update` first.
2. Bump `bevy` to `0.20` and every ecosystem crate to its 0.20-compatible release in the same
   commit.
3. Run each "find" below with `rg` and apply the replacement. Then `cargo check`, then
   `cargo clippy -- -D deprecated`.
4. Run the game and check the "quiet" changes at the bottom. They compile fine but render or
   behave differently.

## Breaking changes, by how often games hit them

| Find (`rg`) | Change |
|---|---|
| `On<(Add\|Insert\|Discard\|Remove\|Despawn),` | `On<Add, T>` → `On<Add<T>>`. Same for the other lifecycle events. Dynamic-component observers use `On<Add<()>>`. Custom events with a bundle generic implement `EventPattern` |
| `Pointer<` | Flat pointer events: `On<Pointer<Click>>` → `On<PointerClick>`, `e.pointer_location.position` → `e.pointer.position` (`Vec2`), `e.pointer_id` → `e.pointer.id`. Generic handlers use `E: PointerEvent` |
| `Interaction` / `Changed<Interaction>` / `bevy::ui::widget::Button` | Deprecated. Use `bevy::ui_widgets::Button` + `Hovered` + `Pressed`, and observe `Activate` |
| `set_if_neq` on `NextState` / `set_state_if_neq` | `set_if_different` / `set_state_if_different` |
| `iter_many(` / `iter_many_mut(` / `iter_many_unique` | Items are now `Result`. Append `.matched()` for the old behaviour |
| `FontSource::SansSerif` / `FontSource::Monospace` / other generic families | `FontSource::sans_serif()`, `FontSource::monospace()`, … |
| `TextFont {` without `font_size` | Default is now `FontSize::Rem(1.)` (scales with `RemSize`). Set `FontSize::Px(20.)` to pin the old size |
| `EditableText` | Add `TextInput` alongside it to get a working text field |
| `Tonemapping::None` | Use `Tonemapping::Linear` if you meant "no curve". `None` is now a raw passthrough |
| `template_value(` in `bsn!` | Remove the wrapper |
| `bsn!` scene references without `@` | Add `@`: `@scene_fn()`, `@{expr}`, `@scene_var` |
| `,` between entities in `bsn!`/`bsn_list!`, `bsn_list![` | Separate entities with `--`, and use `bsn_list! { .. }` |
| `VariantDefaults` derive, partial enum fields in BSN | Remove the derive (needs `Default + Clone`), and spell out every enum field |
| `.wgsl` shaders with `#import`, `#ifdef`, `#{MATERIAL_BIND_GROUP}` | Port to WESL: rename to `.wesl`, `import a::b;`, `@if(FLAG)`, `constants::MATERIAL_BIND_GROUP`, new module paths (`bevy_pbr::render::…`) |
| `OIT_ENABLED` in material shaders | Gate on `MATERIAL_OIT_ENABLED` and pass premultiplied colour to `oit_draw` |
| `bevy::math::primitives` / `bevy_math::bounding` | Moved to `bevy_shape` (still in the prelude) |
| `MeshTag(` | `MeshTag::new(..)` |
| `compute_aabb` | `get_aabb` |
| `Name::from(` / `.into()` from a non-`'static` `&str` | `Name::new(s.to_owned())` |
| `ExclusiveSystemParam` / `ExclusiveFunctionSystem` / `is_exclusive()` | Removed. `&mut World` is a regular `SystemParam` that can appear anywhere in the params |
| `WorldId` param in an exclusive system | `world.id()` or `Local<WorldId>` |
| `FilteredResources` / `FilteredResourcesMut` | Deprecated. Use `QueryParamBuilder` + `Query<FilteredEntityRef>` with `IsResource` |
| `DeferredWorld::query(` | `query_state.query_mut(&mut world)` |
| `UiCameraMapper::current_camera()` compared to `PLACEHOLDER` | Returns `Option<Entity>` now |
| `Val::resolve(` / `BorderRadius::resolve(` | Take extra `em_size`, `rem_size` args |
| `TypeIdMap` | Deprecated. Choose `TypeIdHashMap` or `TypeIdIndexMap` |
| `AssetId::invalid()` | Deprecated. See the official guide |

## Quiet changes (compile fine, behave differently)

- **Screen-space transmission is opt-in.** Add `ScreenSpaceTransmission` to `Camera3d`, or
  glass/water/translucent materials will look different.
- **Sprite draw order at equal Z may change** (sprites now render via `Mesh2d`). Give overlapping
  sprites distinct Z values.
- **Built-in schedules order sets weakly.** If a custom system in `PostUpdate` UI sets, `Render`,
  `Core2d`/`Core3d` or `ExtractSchedule` relied on an earlier set *finishing* through
  channels, atomics or interior mutability, add an explicit `.after(..)`.
- **`Tonemapping::None` without `Hdr`** on `Camera3d` now renders without grading or dither.
- **`TextFont::default()`** follows `RemSize`. If the game changes `RemSize`, default-sized text
  scales too.
- **macOS:** app activation follows `Window::focused` at startup.
- **`RenderDebugOverlay`** is in `DefaultPlugins` now. Check its optional keybindings don't clash
  with yours.

## Before and after, compiled against 0.20

```rust,check
use bevy::{
    picking::hover::Hovered,
    ui::Pressed,
    ui_widgets::{Activate, Button},
};

// BSN needs Default + Clone (or FromTemplate) on every component it names.
#[derive(Component, Default, Clone)]
struct Selectable;

#[derive(States, Debug, Clone, Copy, Default, PartialEq, Eq, Hash)]
enum Screen {
    #[default]
    Title,
    Game,
}

// 0.19: fn on_selectable(add: On<Add, Selectable>) { .. }
fn on_selectable(add: On<Add<Selectable>>, mut commands: Commands) {
    commands.entity(add.entity).observe(on_click);
}

// 0.19: fn on_click(click: On<Pointer<Click>>) { click.pointer_location.position }
fn on_click(click: On<PointerClick>) {
    info!("clicked {} at {}", click.entity, click.pointer.position);
}

// 0.19: Query<&Interaction, (Changed<Interaction>, With<Button>)>
fn start_button(mut commands: Commands) {
    commands
        .spawn((Button, Hovered::default(), Node::default(), children![Text::new("Play")]))
        .observe(|_: On<Activate>, mut next: ResMut<NextState<Screen>>| {
            // 0.19: next.set_if_neq(Screen::Game)
            next.set_if_different(Screen::Game);
        });
}

fn pressed_buttons(buttons: Query<Entity, (With<Button>, With<Pressed>)>) {
    for entity in &buttons {
        info!("{entity} is held down");
    }
}

#[derive(Resource)]
struct Selection(Vec<Entity>);

// 0.19: for t in query.iter_many(&selection.0) { .. }
fn selected(selection: Res<Selection>, query: Query<&Transform, With<Selectable>>) {
    for transform in query.iter_many(&selection.0).matched() {
        let _ = transform.translation;
    }
}

fn label() -> TextFont {
    // 0.19: FontSource::SansSerif, and the default size was a fixed 20px
    TextFont {
        font: FontSource::sans_serif(),
        font_size: FontSize::Px(20.0),
        ..default()
    }
}

// 0.19: bsn_list! [ (template_value(t)), (scene_fn()) ]
fn row(t: Transform) -> impl SceneList {
    bsn_list! {
        t
        Selectable
        --
        @cell()
    }
}

fn cell() -> impl Scene {
    bsn! { Node }
}
```
